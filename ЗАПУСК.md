# PCBuilder ERP — как запустить сайт

Коротко: **двойной клик по `start.bat`** → сервер поднимется сам → браузер откроется
на нужной странице. Ниже — всё, что нужно знать, если что-то пошло не так.

---

## 1. Что нужно (один раз)

| Требование | Зачем | Где взять |
|---|---|---|
| **Node.js 22.5 или новее** | это движок сайта, без него он не работает | <https://nodejs.org> — версия **LTS** |

Проверить, что Node.js уже установлен: откройте `cmd` и введите

```
node -v
```

Если ответ вида `v22.22.2` или `v24.x` — всё готово. Если «не является внутренней или
внешней командой» — установите Node.js по ссылке выше и **перезапустите проводник**
(или просто перезагрузитесь), чтобы система увидела новую программу.

> База данных, библиотеки и картинки уже внутри папки. `npm install` **не нужен** —
> внешних зависимостей у проекта нет.

---

## 2. Запуск (каждый раз)

1. Откройте папку проекта.
2. Дважды щёлкните **`start.bat`**.
3. Появится чёрное окно с логом — **не закрывайте его**, пока работаете с сайтом.
   Через 2–5 секунд само откроется окно браузера.

Скрипт делает всё сам: находит Node.js, поднимает сервер, определяет свободный порт
(обычно 3000) и открывает браузер именно на нём.

### Если браузер не открылся

Откройте вручную один из адресов (порт написан в окне сервера):

| Что | Путь |
|---|---|
| Главная (выбор роли) | `/` |
| **Конфигуратор ПК** | `/builder` |
| Кабинет клиента | `/client` |
| Панель сборщика | `/assembler` |
| Отслеживание доставки | `/track` |
| Состояние системы | `/api/health` |

### Доступы

Паролей в проекте нет. При первом запуске создаётся файл `secrets.local.json`
(в git не попадает) со случайными паролями — сервер печатает их в консоль один раз:

| Роль | Логин |
|---|---|
| Сборщик / администратор | `admin` |
| Сборщик | `assembler` |
| Клиент | `+79990000000` |

Пароль клиента и сотрудников можно поменять в самом файле `secrets.local.json`
(или задать переменные окружения `ADMIN_PASSWORD`, `ASSEMBLER_PASSWORD`,
`CLIENT_PASSWORD`) — при следующем запуске сервер применит новое значение.

---

## 3. Как остановить сервер

- **`stop.bat`** — двойной клик, сервер будет остановлен, окно можно закрыть.
- Либо в окне сервера нажмите **Ctrl + C** (и подтвердите `Y`).

---

## 4. Другие способы запуска

### Через npm

```
cd путь\к\PCBuilder-ERP
npm start
```

### Через VS Code

В папке есть готовая конфигурация `.vscode/launch.json`:

1. `Файл` → `Открыть папку…` → выберите `PCBuilder-ERP`.
2. Нажмите **F5** и выберите **«PCBuilder: запустить сервер»**.

Вторая конфигурация — **«PCBuilder: проверка (smoke-тест)»** — прогоняет весь сценарий
(заказ → оплата → сборка → отправка → получение). Запускать при работающем сервере.

### Если Node.js стоит в необычном месте

Положите `node.exe` в папку **`runtime`** рядом с `start.bat` — лаунчер подхватит его
автоматически, даже если Node.js не прописан в системе.

---

## 5. Проверка работоспособности

```
node tools\smoke-test.js      (сервер должен быть запущен)
node tools\ui-render-test.js  (проверка разметки интерфейса, сервер не нужен)
```

`smoke-test.js` проходит полный путь заказа и проверяет целостность базы.
`ui-render-test.js` проверяет, что все страницы конфигуратора собираются, картинки
на месте и ничего не потерялось.

## 6. Частые вопросы

**`[ОШИБКА] Node.js не найден`**
Node.js не установлен или установлен, но система его ещё не видит. Установите версию
LTS с <https://nodejs.org> и перезапустите `start.bat`. Как вариант — `node.exe` в папку `runtime`.

**`[ВНИМАНИЕ] Установлен Node.js ... а нужна версия 22.5 или новее`**
Слишком старая версия: в ней нет встроенной базы данных `node:sqlite`.
Обновите Node.js до LTS.

**Порт 3000 занят**
Ничего делать не нужно: сервер сам возьмёт 3001, 3002 и так далее, а браузер откроется
на свободном порту. Актуальный порт всегда видно в окне сервера, он же записан в
`data\port.txt`.

**Сайт открывается, но картинок комплектующих нет**
Значит, потерялась папка `images`. Она обязательна. Пересобрать картинки можно скриптом
`tools\make_component_images.py` (нужен Python с библиотекой Pillow) — либо просто
восстановите папку `images` из копии проекта.

**Как сбросить данные к демо-состоянию**
Остановите сервер, удалите файлы `data\pcbuilder.db`, `data\pcbuilder.db-wal`,
`data\pcbuilder.db-shm` и запустите `start.bat` — база создастся заново вместе с
демо-данными и сотрудниками.

**Хочу открыть сайт с телефона в той же сети**
В окне сервера будет напечатан его адрес. На телефоне введите
`http://<IP-компьютера>:<порт>` (IP можно узнать командой `ipconfig`). Учтите, что
брандмауэр Windows может спросить разрешение — нужно разрешить для частных сетей.

## 7. Что внутри

```
start.bat            запуск: находит Node.js, поднимает сервер, открывает браузер
stop.bat             остановка сервера
server.js            сам сервер: интерфейсы, API, печатные формы
config.js            настройки по умолчанию (порт, тарифы, демо-доступы)
index.html           экран-приветствие конфигуратора
app.js, data.js      логика конфигуратора и каталог комплектующих
styles.css           стили конфигуратора
images/              картинки комплектующих и баннер (8 позиций + hero)
public/              интерфейсы клиента, сборщика и трекинга
lib/                 база данных, API, авторизация, настройки, бизнес-логика
tools/               запуск, smoke-тесты и скрипт отрисовки картинок
data/                файл базы SQLite (создаётся при первом запуске) и бэкапы
```
